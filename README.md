# Fitness Tracker

A modern web-based Fitness Tracker built with **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**. The application helps users track workouts, monitor calorie intake, manage body weight, and visualize fitness progress through an intuitive dashboard.

---

## 📌 Features

### 🔐 User Authentication
- User Registration
- Secure Login
- Logout
- Session Management

### 📊 Dashboard
- Personalized welcome screen
- Quick access to all fitness tools
- Clean and responsive interface

### 💪 Workout Tracker
- Start a workout session
- Select muscle groups
- Record exercises
- Log sets, reps, and weights
- View workout history
- View detailed workout sessions

### 🍎 Calorie Tracker
- Add daily food intake
- Track calories consumed
- View food history
- Compare calories consumed with daily calorie goal

### ⚖️ Weight Tracker
- Record body weight
- Maintain weight history
- Visualize progress using charts

### 👤 Profile Management
- Update personal information
- Manage fitness goal
- Update calorie goal

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/deepakch1505-design/Fitness-Tracker.git
```

Move into the project

```bash
cd Fitness-Tracker
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
